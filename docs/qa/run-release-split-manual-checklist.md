# run-release.bat 분할 기능 수동 검증 체크리스트

## 1. 목적

- `run-release.bat`로 실행한 릴리즈 앱에서 `가로 분할`/`세로 분할` 클릭 시 메인 윈도우가 정상 분할되는지 검증한다.
- 과거 이슈 커밋(`94be2a6a718ce54fd8f892656ecc56c561fd5a1a`, `36ab98d93c01e2c6ae4a32f574304e4c64957068`) 재발 여부를 확인한다.
- 탭 전환, 분할 닫기, 레이아웃 프리셋 등 연계 동작의 회귀(regression) 여부를 확인한다.

## 2. 대상 범위

- 실행 스크립트: `run-release.bat`
- 실행 바이너리: `src-tauri/target/release/shellhive.exe`
- UI 기능:
  - 툴바 `가로 분할`
  - 툴바 `세로 분할`
  - 분할 리사이저 드래그
  - 분할 닫기
  - 분할 상태 탭 전환/복원

## 3. 사전 준비

- [ ] `build-release.bat` 또는 `npm run tauri build`가 완료되어 `shellhive.exe`가 존재한다.
- [ ] 테스트 환경에서 기존 Shellhive 프로세스가 모두 종료되어 있다.
- [ ] 테스트용 프로젝트 경로 1개 이상 준비 (예: `D:\work\demo-project`).
- [ ] 테스트 중 화면 녹화 또는 스크린샷 캡처 경로를 확보했다.

## 5. 수동 시나리오 체크리스트

### TC-01 릴리즈 실행 확인

- [ ] `run-release.bat` 실행
- [ ] 앱 메인 윈도우가 정상 오픈됨
- [ ] 초기 탭/터미널이 렌더링됨

기대 결과:
- 배치 스크립트 실행 후 앱이 종료되지 않고 정상 유지된다.

### TC-02 가로 분할 동작 확인

- [ ] 기준 탭 1개 활성화 상태에서 `가로 분할` 버튼 클릭
- [ ] 메인 터미널 영역이 상/하 2개 pane으로 분리됨
- [ ] 각 pane에 터미널 출력/입력이 정상 반응함
- [ ] 분할 리사이저(가로) 드래그 시 크기 비율이 실시간 변경됨

기대 결과:
- 클릭 즉시 레이아웃이 분할되고, 빈 화면/겹침/미반응이 없어야 한다.

### TC-03 세로 분할 동작 확인

- [ ] 단일 탭 상태에서 `세로 분할` 버튼 클릭
- [ ] 메인 터미널 영역이 좌/우 2개 pane으로 분리됨
- [ ] 각 pane의 포커스 전환 및 입력이 정상 동작함
- [ ] 분할 리사이저(세로) 드래그 시 크기 비율이 실시간 변경됨

기대 결과:
- 클릭 즉시 레이아웃이 좌/우로 분할되고, 기존 pane 콘텐츠가 유지되어야 한다.

### TC-04 연속 분할/중첩 분할

- [ ] 가로 분할 후 활성 pane에서 세로 분할 수행
- [ ] 세로 분할 후 활성 pane에서 가로 분할 수행
- [ ] 3개 이상 pane 상태에서 활성 pane 전환 확인

기대 결과:
- 중첩 분할에서도 pane 렌더링 깨짐 없이 구조가 유지된다.

### TC-05 분할 닫기 및 단일 레이아웃 복귀

- [ ] 분할 pane 중 하나 닫기
- [ ] 마지막 분할 pane 닫아 단일 뷰 복귀

기대 결과:
- pane 닫기 후 레이아웃 트리가 정상 축소되고, 단일 뷰로 안전하게 돌아온다.

### TC-06 탭 전환/복원 회귀

- [ ] 분할 상태에서 다른 탭으로 이동
- [ ] 다시 원래 탭 복귀
- [ ] 분할 상태와 활성 pane이 예상대로 유지되는지 확인

기대 결과:
- 탭별 레이아웃이 섞이지 않고, 탭 복귀 시 의도된 분할 상태가 복원된다.

### TC-07 AI 기능 비노출 확인 (현재 릴리즈 정책)

- [ ] 사이드바에서 Claude 섹션/버튼이 노출되지 않음
- [ ] 하단 AI 입력 바가 노출되지 않음
- [ ] `Ctrl+Shift+C`, `Ctrl+Space` 입력 시 AI 관련 UI가 열리지 않음
- [ ] 명령 팔레트에서 AI/Claude 항목이 검색되지 않음

기대 결과:
- 현재 릴리즈 정책(비AI 코어 우선)에 따라 AI 엔트리 포인트가 사용자 UI/입력 경로에서 비활성 상태여야 한다.

## 6. 합격 기준 (Exit Criteria)

- TC-01 ~ TC-07 모두 `Pass`
- 치명(Critical)/높음(High) 결함 0건
