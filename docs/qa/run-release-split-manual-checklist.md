# run-release.bat 분할 기능 수동 검증 체크리스트

## 1. 목적

- `run-release.bat`로 실행한 Release 앱에서 분할/탭/레이아웃 관련 핵심 기능이 정상 동작하는지 검증한다.
- 최근 개선 항목(분할 미니맵, 레이아웃 갤러리, 패널 헤더 정보 강화)이 사용자 관점에서 문제 없이 동작하는지 확인한다.
- 현재 운영 정책에 맞게 AI 관련 UI가 노출되지 않는지 확인한다.

## 2. 검증 범위

- 실행 스크립트: `run-release.bat`
- 실행 파일: `src-tauri/target/release/shellhive.exe`
- 대상 기능:
  - 기본/가로/세로 분할
  - 분할 유지 상태에서 pane 전환
  - 분할 병합/종료
  - 레이아웃 프리셋 선택/적용
  - 레이아웃 갤러리 모달 선택/적용
  - 분할 미니맵 토글/포커스 이동
  - 분할 패널 헤더 상태/경로 요약 표시
  - AI UI 비노출 정책 준수

## 3. 사전 준비

- [ ] `build-release.bat` 또는 `npm run tauri build`로 Release 빌드 완료
- [ ] `src-tauri/target/release/shellhive.exe` 파일 존재 확인
- [ ] 기존 `shellhive.exe` 프로세스 종료
- [ ] 테스트용 프로젝트 경로 1개 이상 준비 (예: `D:\work\demo-project`)
- [ ] 증빙(스크린샷/영상) 저장 경로 준비

## 5. 테스트 케이스

### TC-01 Release 실행 및 경로 독립 실행 확인

- [ ] 저장소 루트에서 `run-release.bat` 실행
- [ ] 저장소 외부 경로(예: `C:\`)에서 절대경로로 `run-release.bat` 실행
- [ ] 앱이 정상 기동되고 초기 터미널이 표시됨

기대 결과:
- 실행 위치와 무관하게 Release 앱이 정상 시작된다.

### TC-02 기본 분할(오른쪽) 동작

- [ ] `기본` 버튼 또는 `Ctrl+\` 입력
- [ ] 기존 pane 유지 + 오른쪽 pane 신규 생성 확인
- [ ] 각 pane에서 입력/출력이 정상 동작

기대 결과:
- VSCode 스타일 기본 분할 흐름으로 즉시 2분할된다.

### TC-03 가로/세로 분할 동작

- [ ] `아래로 분할` 버튼 실행
- [ ] `오른쪽 분할` 버튼 실행
- [ ] 분할 비율 리사이즈(드래그) 동작 확인

기대 결과:
- 가로/세로 모두 정상 분할되고 리사이즈가 반영된다.

### TC-04 분할 상태 유지 전환

- [ ] 분할된 상태에서 다른 pane 클릭
- [ ] 좌측 탭 목록에서 해당 세션 클릭
- [ ] 분할이 풀리지 않고 활성 pane만 전환되는지 확인

기대 결과:
- pane/탭 전환 후에도 분할 레이아웃이 유지된다.

### TC-05 분할 병합 및 종료

- [ ] 분할 헤더 `합치기` 버튼 실행
- [ ] 툴바 `합치기` 버튼 실행
- [ ] 툴바 `분할 종료` 버튼 실행

기대 결과:
- 병합 시 남은 pane 중심으로 자연스럽게 정리되고, 분할 종료 시 단일 화면으로 복귀한다.

### TC-06 레이아웃 프리셋(드롭다운) 적용

- [ ] 툴바 `레이아웃 선택`에서 프리셋 선택
- [ ] `적용` 버튼 실행
- [ ] 선택한 레이아웃(2열/2행/2x2/3열) 구조 확인

기대 결과:
- 선택한 프리셋 구조대로 분할 레이아웃이 생성된다.

### TC-07 레이아웃 갤러리 모달 적용

- [ ] 툴바 `갤러리` 버튼 또는 `Ctrl+Shift+L` 입력
- [ ] 카드 선택 후 `선택 레이아웃 적용` 실행
- [ ] 모달 닫힘 및 레이아웃 반영 확인

기대 결과:
- 시각 프리뷰 기반으로 직관적으로 프리셋을 선택/적용할 수 있다.

### TC-08 분할 미니맵 동작

- [ ] 분할 상태에서 `미니맵` 버튼으로 표시/숨김 토글
- [ ] 미니맵 leaf 항목 클릭으로 해당 pane 활성화
- [ ] 활성 pane 강조 표시 동기화 확인

기대 결과:
- 미니맵 토글과 포커스 이동이 정확히 동작한다.

### TC-09 분할 패널 헤더 정보 표시

- [ ] 각 pane 헤더에 세션명 표시 확인
- [ ] 상태 라벨(연결 중/실행 중/종료됨) 표시 확인
- [ ] 경로 요약(`...\\folder\\subfolder`) 표시 확인

기대 결과:
- 세션 문맥(상태 + 경로)을 헤더에서 즉시 인지할 수 있다.

### TC-10 AI UI 비노출 정책 확인

- [ ] 사이드바에 Claude/AI 관련 버튼이 보이지 않음
- [ ] 하단 AI 입력 바가 보이지 않음
- [ ] `Ctrl+Shift+C`, `Ctrl+Space` 입력 시 AI UI가 열리지 않음
- [ ] 커맨드 팔레트에서 AI/Claude 항목이 검색되지 않음

기대 결과:
- 현재 릴리즈 정책(비AI 코어 우선)과 일치하게 AI UI가 완전히 비노출된다.

## 6. 합격 기준 (Exit Criteria)

- TC-01 ~ TC-10 모두 `Pass`
- Critical/High 결함 0건
- Medium 결함은 우회 가능 + 후속 이슈 등록 완료
