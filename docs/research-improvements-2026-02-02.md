## 2. 부족한 기능 분석

### 2.1 미구현 핵심 기능

| 기능 | 우선순위 | 설명 | 예상 복잡도 |
|------|----------|------|------------|
| **탭 분할 (Split Pane)** | 높음 | 하나의 탭 내에서 터미널 분할 | 높음 |
| **세션 저장/복원** | 높음 | 앱 재시작 시 세션 상태 유지 | 중간 |
| **검색 기능** | 중간 | 터미널 출력 내 텍스트 검색 | 낮음 |
| **세션 이름 변경** | 중간 | 사용자 정의 탭 이름 | 낮음 |
| **프로젝트 그룹화** | 낮음 | 프로젝트를 폴더/카테고리로 분류 | 낮음 |

### 2.2 탭 분할 (Split Pane) 상세

**필요성:**
- 여러 터미널을 한 화면에서 동시에 보기
- 서버 로그 + 개발 작업 병행
- IDE 스타일의 레이아웃

**구현 방안:**
```
┌─────────────────────────────────┐
│  Tab 1  │  Tab 2  │  Tab 3     │
├─────────┬─────────────────────┤
│         │                       │
│ Terminal│      Terminal 2       │
│    1    │                       │
│         ├───────────────────────┤
│         │      Terminal 3       │
└─────────┴───────────────────────┘
```

**기술 스택:**
- CSS Grid 또는 Flexbox 기반 레이아웃
- 리사이즈 핸들 구현 (드래그로 비율 조정)
- 각 분할 영역별 독립 PTY 세션

### 2.3 세션 저장/복원 상세

**필요성:**
- 앱 종료 후 재시작 시 작업 상태 복원
- 프로젝트별 세션 프리셋 저장
- 빠른 작업 환경 재구성

**저장 데이터:**
```json
{
  "sessions": [
    {
      "id": "uuid",
      "projectId": "project-uuid",
      "workingDir": "D:\\Projects\\MyApp",
      "tabIndex": 0,
      "splitLayout": null
    }
  ],
  "activeTabIndex": 0,
  "windowSize": { "width": 1200, "height": 800 }
}
```

**구현 방안:**
- 앱 종료 시 세션 상태 JSON 저장
- 앱 시작 시 세션 복원 옵션 제공
- PTY 히스토리는 저장하지 않음 (보안/용량)

## 4. 프로그램 성숙도 개선

### 4.1 에러 핸들링 강화

**현재 문제점:**
- PTY 에러 시 일부 무시됨
- 사용자에게 명확한 에러 메시지 부족
- 복구 메커니즘 미흡

**개선안:**

| 영역 | 개선 내용 |
|------|----------|
| PTY 에러 | 재연결 시도, 사용자 알림 |
| 파일 I/O | 권한 오류 처리, 대체 경로 제안 |
| 네트워크 | (향후 기능) 타임아웃, 재시도 로직 |
| UI 에러 | 에러 바운더리, 복구 버튼 |

### 4.2 성능 최적화

| 영역 | 현재 | 목표 | 방법 |
|------|------|------|------|
| 앱 시작 시간 | ~3초 | <1초 | 지연 로딩, 코드 분할 |
| 메모리 사용 | ~100MB | <80MB | 스크롤백 제한, 가비지 컬렉션 |
| PTY 출력 | 가끔 지연 | 실시간 | 배칭 최적화, 버퍼 튜닝 |
| 렌더링 | 60fps | 유지 | 가상화, requestAnimationFrame |

### 4.3 테스트 커버리지

**현재 상태:**
- Rust 단위 테스트: 2개 (기본 스캐폴딩)
- JavaScript 테스트: 없음
- E2E 테스트: 없음

**목표:**

| 유형 | 목표 커버리지 | 도구 |
|------|--------------|------|
| Rust 단위 테스트 | 70%+ | cargo test |
| JS 단위 테스트 | 60%+ | Vitest |
| 통합 테스트 | 주요 흐름 | Vitest |
| E2E 테스트 | 핵심 시나리오 | Playwright/WebdriverIO |

### 4.4 코드 품질

| 항목 | 현재 | 목표 |
|------|------|------|
| Rust clippy 경고 | 0 | 유지 |
| JS ESLint | 미설정 | 설정 및 0 경고 |
| TypeScript | 미사용 | 마이그레이션 고려 |
| 코드 문서화 | 부분적 | Rust doc, JSDoc |

### 4.5 로깅 및 디버깅

**현재:**
- 세션 로깅 (선택적)
- 콘솔 로그

**개선안:**

| 항목 | 설명 |
|------|------|
| 구조화된 로깅 | JSON 형식, 로그 레벨 |
| 크래시 리포트 | 에러 수집 (선택적) |
| 성능 메트릭 | 시작 시간, 메모리 추적 |
| 디버그 모드 | 상세 로그, DevTools 자동 오픈 |
