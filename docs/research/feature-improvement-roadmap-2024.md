## 1. 개요

### 1.1 연구 목적

Shellhive 터미널 에뮬레이터의 경쟁력 강화를 위한 기능 개선 방향 연구

### 1.2 연구 범위

- 터미널 기능 (Warp, iTerm2, Windows Terminal 등 벤치마킹)
- 개발자 생산성 향상 기능
- 사용자 경험 개선
- AI 통합 기능
- 협업 기능

### 1.3 연구 방법

- 경쟁 제품 기능 분석
- 개발자 커뮤니티 트렌드 조사
- 최신 터미널 기술 동향 파악

### 4.2 Quick Wins (즉시 구현 가능)

1. **Claude Code 통합** - CLI 호출 래퍼
2. **프로젝트별 환경 변수** - `.shellhive.env` 파일
3. **빌드/테스트 알림** - Tauri 알림 API
4. **실시간 설정 변경** - 설정 파일 watch
5. **드래그 앤 드롭** - 기존 기능 확장

### 4.3 2026-02-07 릴리즈 범위 조정

- 현재 릴리즈는 **비AI 코어 안정화**를 우선합니다.
- AI 기능(Claude 통합, 자연어 변환, AI 에러 설명, AI 스니펫 자동화)은 **운영 범위에서 제외/보류**합니다.
- 우선순위는 다음과 같이 재정렬합니다.
  1. PTY/세션/분할/프로젝트/Git 등 코어 기능 안정성
  2. 설정 스키마 정합성 및 UI-백엔드 일치
  3. 문서/테스트/QA 정합화

## 결론

Shellhive의 중장기 차별화 전략:

1. **코어 안정성 우선**: PTY/세션/프로젝트/분할/Git의 신뢰도 확보
2. **개발자 중심**: 프로젝트 환경 관리, 검색/히스토리, 자동완성 등 생산성 강화
3. **점진적 확장**: 코어 안정화 → 문서/테스트 정합화 → AI/협업 고도화

운영 메모(2026-02-07): AI 기능은 현재 릴리즈 범위에서 제외되며, 추후 별도 페이즈로 재도입합니다.
